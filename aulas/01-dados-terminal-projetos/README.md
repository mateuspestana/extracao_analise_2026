# Aula 1 — Dados, terminal e projetos

Comece por [01-dados-terminal-projetos.ipynb](01-dados-terminal-projetos.ipynb). Ele contém a aula completa, com comandos para Windows e Mac, explicações e conferências em cada etapa.

Depois faça [exercicios/exercicio-01-projeto-e-fontes.ipynb](exercicios/exercicio-01-projeto-e-fontes.ipynb). Os arquivos de exemplo usados na aula estão em `exemplos/arquivos/`.

Ao terminar, você deverá ter a estrutura `01-ambiente/` no seu repositório de trabalhos e um README que documente três fontes de dados.
