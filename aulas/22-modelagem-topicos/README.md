# Aula 22 — Modelagem de tópicos

Abra [22-modelagem-topicos.ipynb](22-modelagem-topicos.ipynb) no Google Colab. A aula usa [500 notícias brasileiras](https://github.com/mauricio-seiji/Dataset-news-articles-pt-br) para explicar TF-IDF, NMF, LDA e leitura crítica de tópicos. O bloco final compara BERTopic em amostra pequena e pede GPU.

Depois faça [exercicios/exercicio-22-modelagem-topicos.ipynb](exercicios/exercicio-22-modelagem-topicos.ipynb). Ele funciona sem GPU. Os textos completos são baixados da fonte ao executar o notebook.
