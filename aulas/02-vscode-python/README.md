# Aula 2 — VS Code e Python

Comece por [02-vscode-python.ipynb](02-vscode-python.ipynb). A aula explica a preparação do ambiente, os primeiros comandos em Python e a leitura de CSV.

Depois faça [exercicios/exercicio-02-leitura-csv.ipynb](exercicios/exercicio-02-leitura-csv.ipynb). O exercício tem seu próprio CSV em `exercicios/data/`.

Use `uv venv .venv` e `uv run`. Consulte o [guia de ambiente](../../tutoriais/uv-requirements.md) somente quando o projeto precisar de bibliotecas externas.
