# Aula 3 — Git, GitHub e repositório profissional

Comece por [03-git-github-repositorio.ipynb](03-git-github-repositorio.ipynb). A aula mostra como criar um repositório privado, registrar commits e enviar o trabalho ao GitHub.

Depois faça [exercicios/exercicio-03-primeiro-repositorio.ipynb](exercicios/exercicio-03-primeiro-repositorio.ipynb). Esse exercício é o entregável da aula: reúne o que você já fez nas Aulas 1 e 2, versiona tudo com Git e envia para um repositório privado no GitHub, com o usuário `mateuspestana` como colaborador.
